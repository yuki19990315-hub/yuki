## 最初に覚える3つ

1. **追加する** — 写真や動画を家族のアルバムへ入れます。
2. **見る** — 写真を大きく表示します。
3. **保存** — 表示中の写真を自分の端末へ保存します。

「削除」や「上書き」は通常の閲覧画面では行いません。分からなくなったときは、画面上部の **TOKIHA** を押すと最初の画面へ戻ります。

---

## iPhone / iPad

### 初回：ホーム画面へ置く

1. 家族から届いたTOKIHAのアドレスを **Safari** で開きます。
2. Safari下部の **共有ボタン（四角から上向き矢印）** を押します。
3. メニューを下へ動かし、**ホーム画面に追加**を押します。
4. 右上の **追加**を押します。次回からホーム画面のTOKIHAを押すだけです。

### 写真・動画を追加する

1. 画面右下の赤い **追加する** を押します。
2. **写真ライブラリ**を選びます。
3. 追加したい写真や動画を押します。複数選んでも構いません。
4. **追加**または**完了**を押します。
5. 「○件の思い出を追加しました」と出れば完了です。

### 端末へ保存する

1. 保存したい写真の **見る** を押します。
2. 右下の **保存** を押します。
3. Safariで確認が出た場合は **ダウンロード**を押します。

## Androidスマートフォン / タブレット

### 初回：ホーム画面へ置く

1. 家族から届いたTOKIHAのアドレスを **Chrome** で開きます。
2. 右上の **︙** を押します。
3. **ホーム画面に追加**または**アプリをインストール**を押します。
4. 確認画面で **追加**または**インストール**を押します。

### 写真・動画を追加する

1. 画面右下の赤い **追加する** を押します。
2. **写真**、**ギャラリー**、または**ファイル**を選びます。
3. 写真や動画を選び、**追加**や**開く**を押します。
4. 「○件の思い出を追加しました」と出れば完了です。

### 端末へ保存する

1. 保存したい写真の **見る** を押します。
2. **保存**を押します。通常は端末の「Download」フォルダへ入ります。

## Windows PC

### 写真を見る・手動でバックアップする

1. **Microsoft Edge**または**Google Chrome**でTOKIHAのアドレスを開きます。
2. 写真は撮影月ごとに表示されます。上部の **検索**から年月や題名でも探せます。
3. 原本をまとめて保存するときは **今すぐPCに保存**を押します。
4. ダウンロードされた `.tar` ファイルを右クリックし、**すべて展開**または対応する展開操作を選びます。

### PC起動時の自動保存

この設定だけは、最初に管理者またはPC操作に慣れた家族が行います。

1. 管理者から「自動バックアップ設定」と読み取り専用トークンを受け取ります。
2. 保存先として、十分な空き容量がある `ピクチャ\TOKIHA` または外付けディスクを選びます。
3. 設定後はWindowsへサインインすると自動実行されます。黒い画面が一瞬表示されても操作は不要です。
4. ファイルは `TOKIHA\撮影年\撮影月` に保存されます。

---

## Mac

### 写真を見る・手動でバックアップする

1. **Safari**または**Google Chrome**でTOKIHAのアドレスを開きます。
2. 原本をまとめて保存するときは **今すぐPCに保存**を押します。
3. ダウンロードした `.tar` をダブルクリックするとフォルダへ展開されます。

### Mac起動時の自動保存

1. 管理者から「自動バックアップ設定」と読み取り専用トークンを受け取ります。
2. 保存先に `ピクチャ/TOKIHA` または外付けディスクを選びます。
3. 設定後はMacへのログイン時に新しい原本だけを自動保存します。
4. ファイルは `TOKIHA/撮影年/撮影月` に保存されます。

## どの端末でも共通の操作

### 昔の写真を探す

- 画面を下へ動かすと、撮影月ごとに古い写真が続きます。
- 上部の **検索**を押し、`海`、`2026年9月`のように入力できます。
- **すべて・写真・動画**で種類を絞れます。

### 撮影日が違うとき

1. 写真の **見る** を押します。
2. **撮影日を直す**を押します。
3. 正しい日を選び、**この日に変更**を押します。

### 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 追加ボタンを押しても進まない | 端末の設定でSafari / Chromeに写真へのアクセスを許可します。 |
| 動画が止まる | Wi-Fiへ接続し、もう一度再生します。 |
| 写真が見つからない | 「すべて」を選び、撮影した年月で検索します。 |
| 日付が違う | 写真を開き「撮影日を直す」を使います。 |
| PCへ自動保存されない | PCがインターネットへ接続されているか、保存先ディスクが接続されているか確認します。 |
| 容量が心配 | 管理者へ連絡します。自分で元写真を削除しないでください。 |

## 管理者向け確認表

- [ ] 利用者のホーム画面へTOKIHAを追加した
- [ ] 「追加する」と「見る」を一緒に1回操作した
- [ ] 問い合わせ先を手順書へ記入した
- [ ] PCバックアップの保存先に十分な空き容量がある
- [ ] 外付けディスクを使う場合、接続方法を説明した
- [ ] バックアップが `撮影年/撮影月` に作られたことを確認した
- [ ] 読み取り専用トークンの失効方法を管理者が把握した

画面名はOSのバージョンや端末メーカーによって少し異なる場合があります。似た名前が見つからない場合は、無理に進まず上記の連絡先へ問い合わせてください。
