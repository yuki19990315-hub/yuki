# 仮想ユーザビリティテスト

## 想定した利用者

- スマホ操作に慣れていない70代の家族
- iPhoneを日常利用する家族
- Androidから動画を追加する家族
- PCで原本を管理する家族の管理者

各利用者について「写真を追加する」「先月の写真を見る」「日付が違う写真を直す」「PCへ保存する」の4タスクを、説明なしで操作する前提で画面と操作手順を確認しました。

## 見つかった問題と修正

| 問題 | 影響 | 修正 |
| --- | --- | --- |
| 虫眼鏡だけでは検索だと分かりにくい | 操作に不慣れな人が機能を発見できない | アイコンに「検索」を併記 |
| モバイルで追加ボタンの文字が消える | 最も重要な操作が「＋」だけになる | 常に「追加する」を表示 |
| 写真右下の矢印の意味が曖昧 | 外部ページへ移動すると誤解する | 「見る」に変更 |
| 検索欄は日付検索を示しているのにタイトルしか検索できない | 「2026年9月」で見つからない | タイトル・年月・日付を検索対象に変更 |
| 撮影日が誤っていても直せない | 古いスキャン写真やメタデータ欠損で月がずれる | ビューアに「撮影日を直す」を追加 |
| 自動バックアップ設定が技術文書へのリンク | 一般利用者には実行内容が分からない | 3ステップの説明ダイアログに変更 |
| 絞り込み状態が支援技術へ伝わらない | スクリーンリーダーで選択中が不明 | `aria-pressed` を更新 |
| 主要操作の文字とタップ領域が小さい | 視力や指先の操作精度によって誤操作する | 14px以上のラベルと48px以上の主要ボタン |
| ファイル解析中に反応がない | 二度押しや離脱につながる | 「読み込み中…」表示と一時的な無効化 |

## 本番接続後に実機で確認すること

仮想評価だけでは、手の震え、屋外での見え方、端末固有の写真選択画面、通信の遅さは再現できません。本番前に少なくともiPhone・Android・Windows PCで各3人、うち半数は65歳以上の利用者に同じ4タスクを実施してもらい、「助けなしで完了できた割合」「完了時間」「誤タップ数」を測定します。目標は全タスク90%以上の自力完了です。

次段階では、アップロード再開、同名ファイル、HEIC、1GB以上の動画、100以上の月がある場合、200%文字拡大、キーボードのみの操作、VoiceOver / TalkBack / NVDAも確認します。
